# 5 วิธีเริ่มเขียนบันทึกออนไลน์ให้สนุกขึ้น

การเขียนบันทึกไม่จำเป็นต้องยาว  
เริ่มจากวันละ 3 บรรทัดก็พอ เพื่อสะท้อนสิ่งดี ๆ ในแต่ละวัน

1. เขียนสิ่งที่ทำให้คุณยิ้ม  
2. สิ่งที่คุณภูมิใจในตัวเอง  
3. สิ่งที่คุณอยากขอบคุณ
